# Η δική μου επιλογή — πιλοτικός οδηγός ψηφοφόρου

Στατική εφαρμογή HTML/CSS/JavaScript για GitHub Pages. Δεν χρειάζεται build, server ή βάση δεδομένων.

## Εκτέλεση

Άνοιξε το `index.html` ή σέρβιρε τον φάκελο με οποιονδήποτε απλό static server.

## Απόρρητο

- Δεν χρησιμοποιείται `localStorage`, `sessionStorage`, cookies ή backend.
- Οι απαντήσεις τηρούνται μόνο σε μεταβλητές JavaScript όσο παραμένει ανοιχτή η σελίδα.
- Με ανανέωση ή κλείσιμο όλες οι απαντήσεις χάνονται.

## Δεδομένα πιλότου

- Ονόματα: ψηφοδέλτια εκλογών 25 Ιουνίου 2023, τέσσερις εκλογικές περιφέρειες Δυτικής Μακεδονίας.
- Κάλυψη: τα οκτώ κόμματα που εξέλεξαν βουλευτές στην αναμέτρηση.
- Και τα 96 προφίλ έχουν τουλάχιστον δύο αξιολογήσιμες θέσεις. Οι προσωπικές δημόσιες παρεμβάσεις επισημαίνονται χωριστά από τις επίσημες θέσεις του κόμματος. Οι κομματικές θέσεις χρησιμοποιούνται ως διαφανές ελάχιστο υλικό όπου δεν εντοπίστηκαν δύο επαρκώς τεκμηριωμένες προσωπικές δηλώσεις και δεν παρουσιάζονται ως λόγια του προσώπου.
- Ο χρήστης δηλώνει συμφωνία από 1 («Δεν συμφωνώ») έως 5 («Συμφωνώ απόλυτα»). Το αποτέλεσμα είναι ο μέσος όρος μόνο των θέσεων που ο ίδιος αξιολόγησε.
- Κάθε θέση διαχωρίζει το ζήτημα, τη συνοπτική στάση, τις προτεινόμενες ενέργειες, την ισχύ της τεκμηρίωσης και τις πηγές. Το υλικό είναι μη εξαντλητικό και χρειάζεται περιοδική δημοσιογραφική επικαιροποίηση.
- Το `data.js` είναι ανεξάρτητο από την εφαρμογή ώστε να μπορεί αργότερα να παράγεται από CSV ή δημοσιογραφικό CMS.

## Δημοσίευση στο GitHub Pages

Ανέβασε τα τέσσερα αρχεία στη ρίζα ενός public repository και ενεργοποίησε Pages από το branch που τα περιέχει. Δεν απαιτείται workflow ή άλλη υπηρεσία φιλοξενίας.
