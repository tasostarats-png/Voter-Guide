# Η δική μου επιλογή — πιλοτικός οδηγός ψηφοφόρου

Στατική εφαρμογή HTML/CSS/JavaScript για GitHub Pages. Δεν χρειάζεται build, server ή βάση δεδομένων.

Η εφαρμογή λειτουργεί ως μία σελίδα με τρεις ανεξάρτητες προβολές στο επάνω δεξί μενού:

- `#parties`: επίσημες θέσεις κομμάτων, χωρίς βαθμολόγηση.
- `#statements`: χρονολογική ροή προσωπικών δηλώσεων υποψηφίων, χωρίς βαθμολόγηση.
- `#match`: ουδέτερη σύγκριση των τεκμηριωμένων προσωπικών θέσεων 2–3 υποψηφίων ανά εκλογική περιφέρεια.

Και οι τρεις προβολές βρίσκονται στο ίδιο `index.html` και η εναλλαγή γίνεται χωρίς φόρτωση άλλης σελίδας.

## Εκτέλεση

Άνοιξε το `index.html` ή σέρβιρε τον φάκελο με οποιονδήποτε απλό static server.

## Απόρρητο

- Δεν χρησιμοποιείται `localStorage`, `sessionStorage`, cookies ή backend.
- Οι προσωρινές επιλογές περιφέρειας, υποψηφίων και θέματος τηρούνται μόνο σε μεταβλητές JavaScript όσο παραμένει ανοιχτή η σελίδα.
- Με ανανέωση ή κλείσιμο όλες οι επιλογές χάνονται.

## Δεδομένα πιλότου

- Ονόματα: ψηφοδέλτια εκλογών 25 Ιουνίου 2023, τέσσερις εκλογικές περιφέρειες Δυτικής Μακεδονίας.
- Κάλυψη: τα οκτώ κόμματα που εξέλεξαν βουλευτές στην αναμέτρηση.
- Οι κομματικές και οι προσωπικές θέσεις δεν αναμειγνύονται. Προφίλ χωρίς επαρκή προσωπική τεκμηρίωση εμφανίζουν σχετική ένδειξη και δεν κληρονομούν τις θέσεις του κόμματος.
- Η προβολή `#match` δεν ζητά πολιτικές προτιμήσεις, δεν υπολογίζει σκορ ή ιδεολογική εγγύτητα και δεν προτείνει ψήφο. Παραθέτει τις διαθέσιμες προσωπικές θέσεις σε παράλληλες στήλες ανά θεματική.
- Η σειρά των προσώπων στον επιλογέα είναι αλφαβητική. Στον πίνακα οι στήλες ακολουθούν τη σειρά επιλογής του χρήστη και δεν αποτελούν κατάταξη.
- Κάθε θέση διαχωρίζει το ζήτημα, τη συνοπτική στάση, τις προτεινόμενες ενέργειες, την ισχύ της τεκμηρίωσης και τις πηγές. Το υλικό είναι μη εξαντλητικό και χρειάζεται περιοδική δημοσιογραφική επικαιροποίηση.
- Το `data.js` είναι ανεξάρτητο από την εφαρμογή ώστε να μπορεί αργότερα να παράγεται από CSV ή δημοσιογραφικό CMS.

## Δημοσίευση στο GitHub Pages

Ανέβασε ολόκληρο το περιεχόμενο του φακέλου στη ρίζα ενός public repository και ενεργοποίησε Pages από το branch που το περιέχει. Δεν απαιτείται workflow ή άλλη υπηρεσία φιλοξενίας.

Οι διαδρομές που μπορούν να κοινοποιηθούν θα είναι:

- `https://USERNAME.github.io/REPOSITORY/#parties`
- `https://USERNAME.github.io/REPOSITORY/#statements`
- `https://USERNAME.github.io/REPOSITORY/#match`
